QISCUS EXPORT - INSTALLING ON A NEW PC
======================================

1. Unzip this folder somewhere permanent, e.g. Documents\qexport
   (not inside Downloads or a temporary folder: the tool keeps its data here).

2. Double-click  install.bat
   - It installs Python automatically if this PC doesn't have it (needs internet).
   - It then walks you through connecting to Qiscus:
       a. Chrome opens multichannel.qiscus.com. Log in with an ADMIN account.
       b. Press F12, click the "Console" tab.
       c. Paste (Ctrl+V) and press Enter. The installer already put the code on your clipboard.
          First time only, Chrome may ask you to type   allow pasting   and press Enter first.
       d. When the console says "Copied!", go back to the installer window and press Enter.
   - It creates two icons on the desktop: "Qiscus Export" and "Qiscus Export (menu)".

3. Open the "Qiscus Export" icon. The window tells you what is downloaded and what to press:
     Download everything   first time takes about 1.5-2.5 hours; pause or stop any time, nothing is lost
     Update new activity   only conversations and campaigns with something new
     Build Excel now       a fresh Excel file from what is downloaded, even while downloading
   Excel files are listed on the right (Complete or Partial) with Open and Show in folder buttons.
   An Excel file is also made automatically when a download finishes or stops.
   The old numbered menu still works: "Qiscus Export (menu)" or qexport.bat.

IF SOMETHING GOES WRONG
- "Login expired": press Refresh login in the window, follow the three steps, then Continue downloads.
  (Logging out of the Qiscus dashboard ends the login the tool uses.)
- The window says another qexport window is downloading: a console run is still going. Wait for it
  to finish, or close that black window; the buttons come back by themselves.
- Something looks wrong: press Copy diagnostics (bottom left) and paste it to support.
  It never contains the login.
- Windows SmartScreen warns about install.bat: click "More info" -> "Run anyway".
- Python installer couldn't run: install Python 3.12 from python.org, tick
  "Add python.exe to PATH", then run install.bat again.
- To repair or update: run install.bat again. Your data and login are kept.

PRIVACY
The exports folder and the .env file contain personal data and a login.
Don't share them, don't put them on shared drives. Full details: README.md
