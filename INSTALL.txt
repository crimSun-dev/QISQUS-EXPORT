QISCUS EXPORT - INSTALLING ON A NEW PC
======================================

1. Open the zip and double-click  Install Qiscus Export.bat
   (no need to extract anything first; that one file contains the whole program).
   - It needs no internet: Python and every library it uses are packed inside.
     (Python is only installed if this PC doesn't already have 3.11 or newer.)
   - It installs Qiscus Export into your user folder and puts two icons on the desktop:
     "Qiscus Export" and "Qiscus Export (menu)".
   - It opens Qiscus Export when it's done.

2. The first time, a Qiscus sign-in window opens by itself. Sign in with an ADMIN account,
   exactly as you normally would. Qiscus Export connects on its own and the window closes.
   (No F12, no console, nothing to copy.)

3. From then on, open the "Qiscus Export" icon. The window tells you what is downloaded and what to press:
     Download everything   first time takes about 1.5-2.5 hours; pause or stop any time, nothing is lost
     Update new activity   only conversations and campaigns with something new
     Build Excel now       a fresh Excel file from what is downloaded, even while downloading
   Excel files are listed on the right (Complete or Partial) with Open and Show in folder buttons.
   An Excel file is also made automatically when a download finishes or stops.
   The old numbered menu still works: "Qiscus Export (menu)" or qexport.bat.

IF SOMETHING GOES WRONG
- "Login expired": press Refresh login (or Sign in again) and sign in in the Qiscus window
  that opens, then press Continue downloads.
  (Logging out of the Qiscus dashboard ends the login the tool uses.)
- The window says another qexport window is downloading: a console run is still going. Wait for it
  to finish, or close that black window; the buttons come back by themselves.
- Something looks wrong: press Copy diagnostics (bottom left) and paste it to support.
  It never contains the login.
- Windows SmartScreen warns about the installer: click "More info" -> "Run anyway".
- Python installer couldn't run: install Python 3.12 from python.org, tick
  "Add python.exe to PATH", then run Install Qiscus Export.bat again.
- To repair or update: run Install Qiscus Export.bat again. Your data and login are kept.
- The sign-in window doesn't open (no Edge or Chrome): in the login dialog, use
  "Other way: copy the login from the Qiscus console".

PRIVACY
The exports folder and the .env file contain personal data and a login.
Don't share them, don't put them on shared drives. Full details: README.md
